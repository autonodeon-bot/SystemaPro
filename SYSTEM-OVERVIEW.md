# Краткое описание системы ЕС ТД НГО

Система учёта оборудования и технической диагностики (ЕС ТД НГО): веб-приложение для администраторов и инженеров, мобильное приложение для полевых обследований, общий backend и API.

---

## Что работает

### Веб-приложение (React, Vite)
- Вход по логину/паролю, роли (admin, chief_operator, operator, engineer, client).
- Управление оборудованием, иерархия (предприятия → филиалы → цеха).
- Задания инженерам, проекты, ОПО (опасные производственные объекты).
- Обследования и чек-листы (создание, просмотр, список).
- Опросные листы, привязка документов и фото к обследованиям.
- Генерация отчётов и экспертиз (Word/PDF), шаблоны отчётов.
- Справочники: компетенции, специалисты, поверки, нормативные документы.
- Клиентский портал, календарь поверок, карта трубопроводов (базово).

### Мобильное приложение (Flutter)
- Вход, офлайн-режим (данные кэшируются).
- Список оборудования и заданий, выбор объекта для обследования.
- Заполнение чек-листа сосуда: основная информация, перечень документов (1–17), карта обследования, фото (табличка, схема контроля), проверки, дефекты ВИК, заключение.
- Фото: камера/галерея, сжатие перед сохранением (до 1920 px, ~500 КБ).
- Сохранение черновика и подписание (SIGNED) с последующей синхронизацией.
- Синхронизация: отправка отчётов одним ZIP-архивом на сервер, прогресс (отчёт X из Y, МБ).
- Экспорт чек-листа в PDF (кнопка в шапке экрана обследования, шаринг файла).
- Толщинометрия, опросы ОПО, опросные листы, выбор поверенного оборудования.

### Backend (FastAPI, PostgreSQL)
- REST API: авторизация (JWT), оборудование, задания, обследования, опросные листы, отчёты, ОПО, пользователи, сертификаты, иерархия.
- Приём ZIP-архива обследования (`POST /api/inspections/upload-archive`): распаковка, создание обследования и опросного листа, сохранение фото.
- Журнал аудита: таблица `audit_log`, логирование создания обследований (CREATE inspection).
- Генерация отчётов (Word), хранение файлов в `/app/uploads/`.
- Деплой: Docker (backend + frontend/nginx), сервер 5.129.203.182.

### Деплой и раздача мобилки
- Деплой по SSH: `deploy-ssh.ps1` (копирование файлов, сборка контейнеров, загрузка APK).
- APK доступен по http://5.129.203.182/mobile/app-release.apk.
