# Система «Монитор» (SystemaPro) — краткий обзор

**Монитор** (платформа **SystemaPro**, ЕС ТД НГО) — единая система технической диагностики нефтегазового оборудования: веб для диспетчеризации и учёта, мобильное приложение для полевых обследований, общий backend и API.

**Полное пошаговое руководство** (веб + мобильное приложение, для пользователей без опыта): [USER-MANUAL-RU.md](./USER-MANUAL-RU.md) — учёт оборудования, задания, обследования, синхронизация, обновление APK, офлайн.

---

## Что работает

### Веб-приложение (React, Vite)
- Вход по логину/паролю, роли (admin, chief_operator, operator, engineer, client).
- Управление оборудованием, иерархия (предприятия → филиалы → цеха).
- Задания инженерам (в т.ч. типы: диагностика, экспертиза, обследование, ЧТО, ПТО, НВО, НВО и ГИ), проекты, ОПО.
- Обследования и чек-листы (создание, просмотр, список).
- Опросные листы, привязка документов и фото к обследованиям.
- Генерация отчётов и экспертиз (Word/PDF), шаблоны отчётов.
- Справочники: компетенции, поверки, нормативные документы.
- Клиентский портал, календарь поверок, карта трубопроводов (базово).

### Мобильное приложение «Монитор» (Flutter)
- Вход, офлайн-режим (кэш и локальная БД).
- Список оборудования и заданий, обследование по объекту.
- Чек-лист сосуда, документы, фото, методы НК, синхронизация с сервером.
- Толщинометрия, опросы ОПО, поверочное оборудование, push-уведомления (при настройке FCM).

### Backend (FastAPI, PostgreSQL)
- REST API: JWT, оборудование, задания, обследования, опросные листы, отчёты, ОПО, пользователи, иерархия.
- Приём архива обследования с мобильного, генерация отчётов.
- Деплой: Docker (backend + frontend/nginx).
