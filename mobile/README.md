# 📱 Мобильное приложение «Монитор»

Мобильное приложение для инженеров диагностики для заполнения и отправки отчетов обследования оборудования.

## 🚀 Возможности

- ✅ Выбор оборудования из списка
- ✅ Заполнение полного чек-листа обследования сосуда
- ✅ Фотофиксация (заводская табличка, схема контроля)
- ✅ Отправка отчетов на сервер
- ✅ **Офлайн и синхронизация:** черновики обследований пишутся в SQLite (`DatabaseService`), при появлении сети выгружаются через `SyncService` (ручной экран «Синхронизация» и фоновая задача `Workmanager`, ~15 мин при сети). Не все сущности кешируются — при сбое повторите синхронизацию.

## 📋 Структура чек-листа

1. **Основная информация**
   - Дата обследования
   - Исполнители
   - Организация

2. **Перечень документов** (17 пунктов)
   - Лицензии, паспорта, сертификаты и т.д.

3. **Карта обследования**
   - Наименование, номера, параметры сосуда
   - Фото заводской таблички

4. **Проверки**
   - Соответствие чертежу
   - Состояние изоляции, покрытия, опор
   - Наличие ремонтов

5. **ЗРА и СППК**
   - Запорно-регулирующая арматура
   - Система предохранительных клапанов

6. **Измерительный контроль**
   - Овальность
   - Прогиб

7. **Контроль твердости**

8. **ПВК и УЗК сварных соединений**

9. **УЗТ (Ультразвуковая толщинометрия)**
   - Схема контроля
   - Точки замеров

10. **Дефекты**

11. **Заключение**

### Требования

- Flutter SDK >=3.2.0
- Android Studio / Xcode
- Подключение к интернету для работы с API

### Быстрый старт

```bash
# 1. Установите Flutter (см. QUICK-START.md)
# 2. Перейдите в папку проекта
cd mobile

# 3. Установите зависимости
flutter pub get

# 4. Запустите приложение
flutter run
```

### Сборка APK

```bash
flutter build apk --release
```

APK будет в: `build/app/outputs/flutter-apk/app-release.apk`

### Генерация кода (для Isar)

```bash
flutter pub run build_runner build
```

## ⚙️ Конфигурация

### Настройка API URL

В файле `lib/services/api_service.dart` измените:

```dart
static const String baseUrl = 'http://5.129.203.182:8000';
```

На адрес вашего сервера.

## 📱 Использование

1. **Запустите приложение**
2. **Выберите оборудование** из списка
3. **Заполните чек-лист**:
   - Основная информация
   - Отметьте наличие документов
   - Заполните карту обследования
   - Добавьте фото
   - Заполните все разделы
4. **Нажмите "Отправить отчет"**

## 🔌 API Endpoints

Приложение использует следующие endpoints:

- `GET /api/equipment` - Список оборудования
- `GET /api/equipment/{id}` - Оборудование по ID
- `POST /api/inspections` - Отправка чек-листа
- `GET /api/inspections` - Список инспекций
