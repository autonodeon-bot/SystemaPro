## ⚠️ Важно: Размещение шаблона чертежа

Для полной функциональности необходимо разместить файл шаблона на сервере:

```bash
# На сервере создайте директорию (если её нет)
mkdir -p /opt/es-td-ngo/backend/reports/assets

# Скопируйте файл шаблона (замените путь на ваш)
# Пример команды для копирования с локальной машины:
pscp -batch -pw "ydR9+CL3?S@dgH" vessel_template.png "root@5.129.203.182:/opt/es-td-ngo/backend/reports/assets/"

# Установите права доступа
ssh root@5.129.203.182 "chmod 644 /opt/es-td-ngo/backend/reports/assets/vessel_template.png"
```

**Примечание:** Файл `vessel_template.png` должен быть подготовлен заранее. Это изображение схемы сосуда для использования в качестве шаблона при отсутствии фото схемы контроля.
