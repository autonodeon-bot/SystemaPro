## 1. 📅 Система планирования и календаря обслуживания (Maintenance Scheduling)

### Описание
Автоматическое планирование периодических проверок и обслуживания оборудования на основе нормативных требований, истории диагностик и ресурса оборудования.

### Функционал:
- **Календарь обслуживания** с визуализацией запланированных работ
- **Автоматическое создание задач** на основе:
  - Сроков действия сертификатов инженеров
  - Периодичности проверок по нормативным документам
  - Ресурса оборудования (следующая проверка)
  - Результатов предыдущих диагностик
- **Умное планирование** с учетом:
  - Загруженности инженеров
  - Приоритетов оборудования
  - Сезонности работ
  - Доступности оборудования
- **Напоминания** за 30, 14, 7 дней до срока
- **Перенос и отмена** задач с историей изменений

### Технические детали:
```python
# Новая модель
class MaintenanceSchedule(Base):
    equipment_id: UUID

    interval_days: int

    assigned_engineer_id: UUID
    priority: str  # LOW, MEDIUM, HIGH, CRITICAL
    status: str  # SCHEDULED, IN_PROGRESS, COMPLETED, OVERDUE, CANCELLED
```

### Преимущества:
- ✅ Предотвращение просрочек проверок
- ✅ Оптимизация загрузки инженеров
- ✅ Соответствие нормативным требованиям
- ✅ Снижение рисков аварий

### Аналоги в мировых системах:
- SAP PM (Plant Maintenance)
- IBM Maximo

```python
# Backend: генерация QR-кодов
import qrcode
def generate_equipment_qr(equipment_id: str) -> bytes:
    url = f"https://app.example.com/equipment/{equipment_id}"
    qr = qrcode.QRCode(version=1, box_size=10, border=5)
    qr.add_data(url)
    qr.make(fit=True)
    img = qr.make_image(fill_color="black", back_color="white")
    return img

# Mobile: сканирование
# Использование библиотеки qr_code_scanner или mobile_scanner
```

  - История всех подписей
  - Время подписания
  - IP-адрес и устройство
  - Невозможность изменения после подписания
