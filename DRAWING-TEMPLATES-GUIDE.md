# Шаблоны чертежей с точками замеров — руководство

Версия 3.27.0 вводит новый модуль «Шаблоны чертежей»: инженер-эксперт загружает растровую схему оборудования (PNG/JPG), расставляет на ней точки замеров (толщины/твёрдости/прочие), а инженеры в полевом приложении подтягивают эти точки прямо в форму замеров.

## Для администратора / ведущего инженера (веб)

### 1. Создать шаблон

1. В боковом меню раздел **Инструменты → Шаблоны чертежей**.
2. Кнопка **«Загрузить шаблон»** → откроется форма.
3. Заполнить:
   - **Наименование** — например, «Сепаратор С-101, вид сверху».
   - **Категория** — vessel / pipeline / heat_exchanger / other.
   - **Оборудование** — выбрать конкретный объект, **или**
   - **Тип оборудования** — если чертёж типовой для всего класса.
   - **Файл** — PNG или JPG, рекомендуемый размер до 4000×4000 px.
4. **Сохранить**.

### 2. Расставить точки замеров

После сохранения откроется интерактивный редактор:

- Колёсико мыши — зум.
- Удержать + перетащить — pan.
- **Клик по изображению** — добавить точку.
- Клик по точке — открыть панель с полями:
  - **Метка** (T1, T2, H-05, …)
  - **Тип** (thickness / hardness / other)
  - **Ожидаемое значение** (опционально, для сверки в поле)
  - **Примечание**
- Перетаскивание точки мышью — изменить позицию.
- **Сохранить точки** — фиксирует набор на сервере.

Координаты хранятся в процентах относительно размера исходного изображения, поэтому чертёж корректно отображается на любом экране.

### 3. Версионирование

Каждое редактирование увеличивает поле `version` шаблона. Мобильное приложение видит новую версию при delta-синхронизации и перекачивает только изменившиеся чертежи.

## Для инженера в поле (мобильное)

### Вариант A — из экрана толщинометрии

1. Открыть задание → выбрать объект.
2. Начать **Толщинометрию**.
3. Кнопка **«Шаблон из библиотеки»** в верхней части экрана.
4. Из списка выбрать нужный чертёж (фильтр: «для этого оборудования» / «все»).
5. Точки из шаблона автоматически попадут в форму замеров.
6. При тапе по любой точке на схеме — откроется ввод фактического значения.

### Вариант B — из меню инженера

Дашборд → **Схемы и чертежи** → выбрать шаблон → редактировать точки (добавление/перетаскивание допустимо, отправка изменений обратно в БД идёт в рамках synchronization queue).

### Offline

Все чертежи (изображения + точки) кэшируются локально в sqflite. После первой успешной синхронизации задания инженер может работать без сети: схемы доступны, добавленные точки уходят в очередь и отправятся при появлении связи.

## Для разработчика

### Бэкенд

- Модели: `DrawingTemplate`, `DrawingTemplatePoint` в `backend/models.py`.
- Миграция: `backend/alembic/versions/005_drawing_templates.py` + fallback-SQL в `main.py::_run_migrations`.
- Роутер: `backend/drawing_templates_api.py`:
  - `GET  /api/drawing-templates?equipment_id=&equipment_type_id=`
  - `GET  /api/drawing-templates/sync?since_version=`
  - `GET  /api/drawing-templates/{id}`
  - `GET  /api/drawing-templates/{id}/image` → бинарь
  - `POST /api/drawing-templates` (multipart: meta + file)
  - `PATCH /api/drawing-templates/{id}` (meta/points)
  - `PUT  /api/drawing-templates/{id}/image` (замена картинки)
  - `DELETE /api/drawing-templates/{id}` (soft)
- Файлы: `/app/uploads/drawing_templates/<uuid>.<ext>`.

### Веб

- Страница: `pages/DrawingTemplatesManager.tsx` (/drawing-templates).
- Интеграция в карточку оборудования: `pages/EquipmentDetails.tsx`, секция `EquipmentDrawingTemplatesSection`.

### Мобильное

- Модели: `mobile/lib/models/drawing_template.dart`.
- Сервис: `mobile/lib/services/drawing_templates_service.dart` (кэш картинок в FS, БД в sqflite).
- Экраны: `drawing_template_picker_screen.dart`, `drawing_annotation_screen.dart`.
- Синхронизация: `sync_service.dart::syncDrawingTemplates` + prefetch по заданиям.

## Частые вопросы

- **Что если инженер добавил точку, а на сервере её нет?** → новые точки помечаются `origin='mobile'`; при синхронизации они создаются в БД с сохранением автора.
- **Можно ли удалить шаблон?** → только soft-delete, файл в `uploads/` не удаляется (чтобы не ломать историю замеров, ссылающихся на чертёж).
- **Лимит размера файла?** → 20 MB на картинку (настраивается в `drawing_templates_api.py::MAX_IMAGE_SIZE`).
