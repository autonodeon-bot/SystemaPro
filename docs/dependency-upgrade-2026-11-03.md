# Обновление зависимостей SystemaPro — 03.11.2026

## Изменения

- Node для сборки: 20 → 24.22.2 LTS; версия зафиксирована в `.node-version`, CI и Dockerfile. Сайт обслуживает nginx; Node не является сервером приложения.
- Vite 8.3.5, React plugin 6.2.1, Vitest 4.1.12, React Router 7.18.5. React остаётся в ветке 18.
- Обновлены FastAPI, Starlette, python-multipart, requests, Pillow, pypdf, aiosmtplib и транзитивные зависимости.
- python-jose заменён на PyJWT 2.15.1; удалены jose/ecdsa/rsa/pyasn1 из образа. Секрет JWT и формат пользовательских паролей сохранены. Старый HS256 JWT проверен отдельным тестом совместимости.
- Python runtime зависимости закреплены с SHA-256 в `backend/requirements.lock`; Docker и CI устанавливают их с проверкой хешей.
- В серверный образ добавлен отсутствовавший `epb_vessel_layout.docx`; схема `report_fields.json` приведена к версии мобильного приложения (добавочные поля сосуда и ЭПБ).

## Проверки

- Локально: 479 backend-тестов, 72 frontend-теста, 66 мобильных тестов; TypeScript и production build успешно.
- В Linux-образе выпуска: 479 backend-тестов успешно.
- Все 44 формы отчётов сгенерированы; расширенная проверка заполнителей с изображениями успешна.
- Отдельные PostgreSQL 18 и API в изолированной Docker-сети: реальный вход, отказ при неправильном пароле, загрузка ZIP v2, повторная загрузка без дублей, асинхронная генерация и скачивание DOCX/PDF по сосуду.
- Проверены включение 2FA, запрос второго фактора при входе, TOTP, однократность резервного кода и запрет сброса включённой 2FA.
- npm audit и pip-audit фактически установленного Linux runtime: известных уязвимостей не найдено на дату проверки. Это не является аудитом ОС или гарантией отсутствия всех уязвимостей приложения.
- Проверки выполняются автоматически; ручной проход интерфейса на физическом телефоне не выполнялся.

## Выпуск и откат

Обновление опубликовано на neftcontrol.ru. Backend healthy, база подключена, главная страница HTTP 200, защищённый API без токена HTTP 401. Мобильная версия 3.7.36 (79) сохранена. Резервная копия выпуска: `/opt/es-td-ngo/dependency-backup-20261103-120930`.

Образы: `systemapro-backend:dependencies-20261103`, `systemapro-frontend:dependencies-20261103`.
Скрипт выпуска: `tools/deploy-dependencies-20261103.sh`. Перед переключением сохраняет исходники и compose override в `/opt/es-td-ngo/dependency-backup-<дата-время>`; при ошибке проверки восстанавливает прежние образы и файлы.
Для последующего ручного отката восстановить сохранённый `docker-compose.audit.yml`, выполнить `docker compose -f docker-compose.yml -f docker-compose.audit.yml up -d --no-build backend frontend`, затем `docker exec es_td_ngo_frontend nginx -s reload` и проверить `/health` через localhost:8000. Миграций схемы БД в этом обновлении нет.
