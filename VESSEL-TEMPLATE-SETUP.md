# Инструкция по настройке шаблона чертежа сосуда

## Описание

Для генерации отчетов по сосудам и ресиверам используется шаблон чертежа сосуда, который применяется автоматически, если пользователь не загрузил фото схемы контроля в мобильном приложении.

## Установка шаблона

1. Подготовьте изображение шаблона чертежа сосуда (PNG или JPG)
   - Рекомендуемый размер: 1200x1600 пикселей или больше
   - Формат: PNG (для прозрачности) или JPG
   - Изображение должно содержать схему сосуда с обозначениями для точек замера

2. Разместите файл на сервере:
   ```bash
   # На сервере создайте директорию если её нет
   mkdir -p /opt/es-td-ngo/backend/reports/assets
   
   # Скопируйте файл шаблона
   cp vessel_template.png /opt/es-td-ngo/backend/reports/assets/vessel_template.png
   
   # Установите права доступа
   chmod 644 /opt/es-td-ngo/backend/reports/assets/vessel_template.png
   ```

3. В Docker контейнере путь будет: `/app/reports/assets/vessel_template.png`

## Использование в мобильном приложении

Мобильное приложение автоматически использует шаблон, если:
- Тип оборудования - сосуд или ресивер (type_code содержит "VESSEL" или type_name содержит "сосуд"/"ресивер")
- Пользователь не загрузил фото схемы контроля

## Структура шаблона

Шаблон должен содержать:
- Вид сосуда сверху (круг с осями)
- Вид сосуда сбоку (развертка обечайки)
- Вид сосуда снизу (с опорами)
- Обозначения для точек замера (X, Y координаты)
- Условные обозначения (легенда)

Пример структуры можно посмотреть в файле `c:\DIANEKS\Отчет\reciver.md` (изображение схемы контроля).

## Обновление шаблона

Для обновления шаблона:
1. Замените файл `vessel_template.png` на новый
2. Перезапустите backend контейнер (если нужно):
   ```bash
   docker restart es_td_ngo_backend
   ```

## Поддержка других типов оборудования

Для других типов оборудования (трубопроводы, резервуары и т.д.) можно создать аналогичные шаблоны:
- `pipeline_template.png` - для трубопроводов
- `tank_template.png` - для резервуаров
- И т.д.

Код автоматически определит тип оборудования и использует соответствующий шаблон.
