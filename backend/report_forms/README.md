# Формы технического отчёта (Приложение_форма ТО)

Официальные Word-шаблоны отчётов по видам оборудования.

| Файл | Назначение |
|------|------------|
| `technical_report_forms.json` | Реестр форм (`to-1` … `to-44`) |
| `to-N.docx` / `to-N.doc` | Шаблоны (ASCII-имена — для деплоя без поломки кириллицы) |
| `original_file` в JSON | Исходное имя из каталога «Приложение_форма ТО» |

При генерации ТО система копирует шаблон и заполняет таблицы данными обследования.

| Форма | Статус заполнения |
|-------|-------------------|
| **to-1** сосуды | Полный: таблицы, схемы, фото, прил. 8–9, подписи |
| **to-13** трубопроводы | Основной блок + УЗТ + схемы/фото |
| **to-25** резервуары | Протоколы УЗТ/УЗК + схемы/фото |
| Остальные | Каталог подключён; заполнители — по мере внедрения |

PDF: Word-форма → LibreOffice (`soffice`) → PDF; при отсутствии LO — fallback ReportLab.

Источник: `ФОРМЫ/Приложение_форма ТО`.
